# Pastão Digital - Sistema Litúrgico Musical 🎵

O **Pastão Digital** é um aplicativo focado na organização e execução de repertórios musicais para celebrações religiosas, projetado especificamente para rodar de forma **Off-line First**. O objetivo principal é substituir as pastas físicas de folhas por um sistema digital ágil, imune a falhas de internet durante as celebrações.

## 🚀 Funcionalidades Principais
*   **Modo Off-line First:** Execução de roteiros, busca no acervo local, transposição de tons e rolagem automática funcionam 100% sem internet.
*   **Organizador de Celebrações:** Criação de roteiros com blocos litúrgicos fixos e customizáveis.
*   **Modo Simular (Imersivo):** Interface limpa em tela cheia para o momento da celebração, com rolagem automática inteligente.
*   **Sistema Duplo de Cadastro:** Importação automatizada via links (Cifra Club) no modo on-line e edição manual robusta para salmos ou composições próprias.
*   **Músicas Fixadas (Modo Pânico):** Atalhos rápidos na tela inicial para músicas coringas em caso de mudanças repentinas do celebrante.
